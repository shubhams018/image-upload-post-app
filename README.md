# Image Upload Post App

A basic full-stack application built while learning backend development.

## Features

- Create a post with a caption
- Upload an image
- Store uploaded images using ImageKit
- Store post information in MongoDB
- Fetch posts from the backend
- Display posts in the React frontend
- Navigate to the feed after creating a post

## Tech Stack

### Frontend
- React
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- Multer
- ImageKit

## What I learned

- Express API creation
- MongoDB and Mongoose
- REST APIs
- Multer memory storage
- Handling image buffers
- ImageKit integration
- Environment variables
- Connecting frontend with backend
- Debugging API and upload issues
